# 🎓 동신대학교 교수학습지원센터(CTL) 공식 스마트 홍보 앱

> **"학생이 행복한 대학, 내일을 여는 스마트 배움의 길잡이"**  
> 동신대학교 재학생 및 교원을 위한 비교과 프로그램 신청, 30초 AI 맞춤 진단, 24시간 챗봇, 비교과 드림마일리지 장학 포털 웹 앱입니다.

---

## 📱 주요 기능 소개

### 1. 🏠 스마트 홈 (Home)
- **히어로 슬라이더 배너**: 2026-1학기 러닝파트너 24기, 생성형 AI 워크숍, 1:1 MLST 학습컨설팅 홍보
- **4대 퀵 액션 바**: 프로그램 신청, AI 맞춤진단, 1:1 코칭예약, 마일리지 혜택 바로가기
- **동신 CTL 핵심 성과 대시보드**: 연간 참여 학생 3,480+명, 지원 장학금 1.85억+, 학생 만족도 98.7%
- **실시간 인기 & 마감임박 프로그램 카드**: 정원 현황 및 마일리지 표시
- **생생 우수 참여 후기**: 성적 향상(2.9 → 4.25) 및 공모전 우수팀 선배들의 리얼 후기

### 2. 📚 CTL 비교과 프로그램 (Programs)
- **카테고리 필터**: 학습공동체(러닝파트너/튜터링), AI·에듀테크, 학습법·특강, 1:1 컨설팅, 교수지원
- **실시간 검색**: 프로그램명, 키워드 검색
- **원클릭 상세 모달 & 모의 신청**: 커리큘럼, 일정, 참여 혜택 확인 후 즉시 신청 폼 작성 (신청 시 축하 컨페티 효과 및 보너스 마일리지 적립)
- **찜하기(북마크)**: 관심 프로그램 보관함 관리

### 3. 🤖 AI 학습코치 '동신이' (AI Study Coach)
- **30초 맞춤 프로그램 자가진단**: 학년과 학습 고민을 선택하면 AI 마스코트 '동신이'가 최적의 CTL 프로그램을 맞춤 추천하고 신청으로 연계
- **24시간 인터랙티브 챗봇**: 러닝파트너 신청 조건, 드림마일리지 지급 시기, 스터디룸 예약 등 실시간 질의응답

### 4. 💎 비교과 드림 마일리지 & 리워드 (My Mileage)
- **마일리지 VIP 대시보드**: 골드 러너 등급 게이지 및 다음 장학금 티어까지 남은 점수 확인
- **데일리 배움 퀴즈 (+20P)**: 매일 동신대 상식 퀴즈를 풀고 즉시 마일리지 적립
- **리워드 교환소**: 카페드림 쿠폰, 동신대 후드티, 스마트 패키지, 비교과 성취 장학금(현금) 교환
- **나의 프로그램 신청 내역**: 현재 신청된 프로그램 이력 실시간 관리

### 5. 🏢 센터소개 & 공간안내 (About & Space)
- **특화 학습 공간**: 스마트 러닝 라운지, 그룹 협동 스터디룸(Room A/B/C), 첨단 크리에이터 스튜디오
- **공간 무료 예약 모달**: 이용 목적, 날짜, 인원 입력 후 즉시 예약
- **오시는 길 & 문의**: 동신대 중앙도서관 2층 위치, 직통 전화(061-330-3114), 이메일 및 대표홈 링크

### 6. 🎛️ 디바이스 뷰 & 테마 커스텀
- **모바일 앱 뷰 (기본)**: 실감 나는 스마트폰 프레임, 다이내믹 아일랜드, 실시간 시계 지원
- **와이드 웹 뷰**: 데스크톱/태블릿 화면에 꽉 차는 와이드 대시보드 레이아웃
- **다크 모드 / 라이트 모드**: 눈이 편안한 감각적인 다크 네이비 테마 토글

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기
- 폴더 내 `index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등 브라우저에서 바로 이용할 수 있습니다. (외부 빌드 없이 100% 동작)

### 방법 2: 로컬 웹 서버 실행 (현재 포트 8080 실행 중)
- 웹 브라우저에서 [http://localhost:8080/](http://localhost:8080/) 접속
- 서버를 직접 재실행하려면 터미널에서:
  ```powershell
  python -m http.server 8080
  ```
